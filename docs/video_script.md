# 测试视频录制脚本

建议录制 3～5 分钟，分辨率 1280×820，画面同时保留应用窗口和数据库查看窗口（可用 DB Browser for SQLite 或 Navicat）。

1. **启动与登录失败**：启动 `HospitalQt.exe`，输入 `admin / wrong`，点击登录，展示红色“用户名或密码错误”。
2. **登录成功与列表**：改为 `admin / 123456`，进入患者管理页，展示 10 条预置记录和左下角开发者信息。
3. **查询**：在搜索框输入“陈志强”，展示过滤结果；再输入“不存在的患者”，展示 0 条和“未找到符合条件的患者”，点击重置恢复 10 条。
4. **新增**：点击“新增患者”，填写姓名、身份证号、性别、出生日期、身高、体重、手机号，保存；展示列表新增一行，并在数据库中刷新 `patient` 表确认。
5. **修改**：选中新记录，点击“编辑”，修改姓名或手机号，保存；展示列表刷新和数据库中的新值。
6. **删除确认**：选中记录，点击“删除”，先展示确认对话框，点击“取消”；再次删除并点击“确认删除”，展示列表少一行、数据库中记录消失。
7. **异常场景**：用无效数据库路径启动（或展示错误对话框截图），说明数据库连接失败提示；同时可展示重复身份证号新增失败。
8. **Git 历史**：切换到终端执行 `git log --oneline --graph --decorate -10`，展示提交历史。

录制时每个操作停留 2～3 秒，确保能看清操作前后表格行数、状态栏提示和数据库记录变化。
